- එකම codebase එකක් — image processing logic එකයි UI එකයි එකම process එකේ.

## 4. `info.xml` එක — structure + explanation

Admin staff දෙන file එක. Student indices + subject info තියෙනවා. Program එක මේක read කරලා, image එකෙන් detect කරගත්ත rows එක්ක **map** කරනවා.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<attendance>
    <subject>
        <code>CS402.3</code>
        <title>Computer Graphics and Visualization</title>
        <lecturer>Dr. Rasika Ranaweera</lecturer>
        <date>2019-07-12</date>
        <hall>103</hall>
    </subject>
    <students>
        <student>
            <no>1</no>
            <index>10000409</index>
            <title>Ms</title>
            <name>M S Dilshanika Perera</name>
        </student>
        <student>
            <no>2</no>
            <index>10009301</index>
            <title>Mr</title>
            <name>C W M A Shehan Abeyrathne</name>
        </student>
        <!-- ... ඉතුරු students ... -->
    </students>
</attendance>
```

**Python වලින් read කරන්නෙ මෙහෙම** (`src/info_parser.py`):

```python
import xml.etree.ElementTree as ET

def parse_info(xml_path):
    tree = ET.parse(xml_path)
    root = tree.getroot()

    subject = {
        "code":  root.findtext("subject/code"),
        "title": root.findtext("subject/title"),
        "date":  root.findtext("subject/date"),
    }

    students = []
    for s in root.findall("students/student"):
        students.append({
            "no":    int(s.findtext("no")),
            "index": s.findtext("index"),
            "name":  s.findtext("name"),
        })

    return subject, students
```

> XML row order එකයි signing sheet එකේ row order එකයි එකම නිසා — image එකෙන් row `n` එකේ signature තියෙනවද කියලා බලලා, XML එකේ student `n` එක්ක map කරනවා.

## 5. SQLite schema (`src/database.py`)

```sql
CREATE TABLE IF NOT EXISTS attendance (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    student_idx TEXT NOT NULL,
    student_name TEXT,
    subject_code TEXT,
    date        TEXT,
    status      TEXT CHECK(status IN ('present','absent')),
    UNIQUE(student_idx, subject_code, date)
);
```

`status` එක image processing එකෙන් තීරණය වෙනවා: signature cell එකේ ink pixels ප්‍රමාණයක් තිබ්බොත් `present`, නැත්නම් `absent`.

## 6. Python approach (pipeline එක කෙටියෙන්)

`src/image_processing.py` වල core steps:

1. **Load** — `cv2.imread()`
2. **Greyscale** — `cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)`
3. **Denoise / blur** — `cv2.GaussianBlur()` (L3.2 slides)
4. **Binarize** — `cv2.adaptiveThreshold()` හෝ Otsu (`cv2.THRESH_OTSU`)
5. **Table detect** — horizontal/vertical lines detect කරලා (morphology — L4.3 dilation/erosion) cells වෙන් කරනවා
6. **Signature check** — signature column එකේ එක එක cell එකේ **non-white (ink) pixel count** එක ගණන් කරලා threshold එකක් එක්ක compare → present/absent

හැම step එකෙම output එක `output/processed/` වලට save කරන්න → report screenshots.
