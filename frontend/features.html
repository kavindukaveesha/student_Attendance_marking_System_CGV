Feature Sandbox

Standalone demos for F1 – F5 · one owner per module

← Dashboard F1 F2 F3 F4 F5 API Docs
F1

Image preprocessing · Member 1

POST /api/features/image-processing/preview

Loads the photo, converts to greyscale, and applies Gaussian smoothing.

F2

Geometric correction · Member 2

POST /api/features/transforms/deskew

Detects skew via Hough lines, rotates, then resizes to 1000 × 1400.

F3

Table & cell segmentation · Member 3

POST /api/features/table-extraction/cells

Binarizes, detects grid lines with morphology, extracts each student's signature cell.

F4

Signature detection · Member 4

POST /api/features/signature-detection/check

Binarizes and measures ink ratio. Decides present / absent against a configurable threshold.

F5

Signature recognition · Member 5

POST /api/features/signature-recognition/compare

ORB feature matching between a sample cell and a reference signature. Returns a similarity score in [0, 1].

Each panel above is owned end-to-end by one group member · commits stay within their folder.
